# Optional Module: Tailwind CSS v4 + shadcn/ui Configuration

Lazy-load this reference **ONLY** if Tailwind CSS with shadcn/ui is selected.

> [!CAUTION]
> **Strict Role Boundary — Config Only (No UI Primitives):** This module configures the foundational utilities (`cn()`), path aliases, and CSS variables required by shadcn/ui. Never pre-install unrequested UI component primitives (e.g., `button.tsx`, `dialog.tsx`, `dropdown-menu.tsx`). Leave component installation to the developer via `npx shadcn@latest add <component>`.

---

## 1. Dependencies & Installation

```bash
npm install clsx tailwind-merge class-variance-authority
```

---

## 2. Canonical `cn()` Class Merge Utility

Create the foundational helper that merges Tailwind classes and resolves utility conflicts:

### `src/lib/utils.ts`
```typescript
import { clsx, type ClassValue } from "clsx";
import { twMerge } from "tailwind-merge";

export function cn(...inputs: ClassValue[]): string {
  return twMerge(clsx(inputs));
}
```

---

## 3. Path Alias Verification

Ensure `@/` is mapped in `tsconfig.json` and `vite.config.ts`:

### `tsconfig.json`
```json
{
  "compilerOptions": {
    "baseUrl": ".",
    "paths": {
      "@/*": ["./src/*"]
    }
  }
}
```
